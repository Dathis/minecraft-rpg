# План

Цель: RPG «как Скайрим» в Майнкрафте, где админ всё настраивает в игре, а игроки играют. Java + Bedrock.

## Готово
- База: модули, конфиг, хранилище, меню-сундуки, ввод через чат, `/rpg`.
- Предметы, оружие (урон от-до, крит, вампиризм) и броня (защита, +ХП, регенерация): `/create-item`.
- Цифры урона и полоска ХП цели.
- Своё ХП и броня без ванильных пределов, формула снижения урона, ХП над хотбаром (`modules.health`).
- Мобы: ранг, ХП, урон, снаряжение, лут, яйцо призыва, зоны спавна с респавном: `/create-mob`.
- Запрет естественного спавна монстров.
- Тестовый сервер одним кликом: `test-server.bat`.
- NPC: шаблоны, скин головы, броня и оружие, точки в мире, торговля (`/create-npc`).
- Квесты: убить, принести, поговорить, разведать; награды, цепочки, книги-статусы, журнал (`/create-quest`, `/quests`).
- Защита мира, зоны строительства и зоны добычи (замена блока, добыча в инвентарь, возврат через время): `/create-region`.
- Участки игроков: земли под участки, бумаги 15x15 / 30x30 / 60x60, выбор места на карте, помощники (`/plot`).
- Уровни персонажа (20): опыт за мобов и квесты, уровни у мобов и предметов, штраф за разницу 5+ уровней, +ХП за уровень (`/level`).

## Дальше (из исходного описания)
- **Автопосадка деревьев** (`modules/tree`): после сруба на месте ствола сразу саженец. Пока можно обойтись зоной
  добычи: бревно → пусто, возврат через время.
- Флаги зон (PvP, вход только для своих).
- Участки: продажа за игровую валюту (когда появится экономика), аренда с оплатой раз в N дней.
- **Диалоги** (`modules/dialog`): реплики с вариантами ответа через меню-сундук.

- **Полные скины NPC**: на Paper 1.21.9+ есть сущность Mannequin (модель игрока с любым скином). Сейчас скин —
  только голова на человекоподобном мобе.

## Идеи
- Значок «!» над квестодателем, у которого есть доступный квест.
- Пробивание брони у оружия (% брони цели, который игнорируется), магический урон мимо брони.
- Окно `/stats` со статами игрока.
- Уровни: опыт группе (делить опыт между игроками, бившими моба), урон за уровень, очки навыков на уровень,
  цвет уровня моба в полоске ХП по разнице с игроком.
- Больше перков оружия (поджог, замедление и т.д.).
- Кнопка «Обновить описание» у выданных предметов после изменения шаблона.
